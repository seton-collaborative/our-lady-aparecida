# Documents

The file itself goes in `documents/` at the top of the site; this entry says what it is.

```yaml
title:   { pt: "...", en: "..." }
file: documents/2026-12-bulletin.pdf
show_from: 2026-12-01               # optional
hide_after: 2026-12-31              # optional
```

The financial reports in `documents/financials/` are listed on the locked
Financial Reports page and are not managed here.
