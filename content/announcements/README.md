# Announcements

One file per announcement, named `YYYY-MM-DD-short-name.yml`. None yet.
The editing tool will add these; the homepage section that shows them comes with the tool.

```yaml
title:   { pt: "...", en: "..." }
body:    { pt: "...", en: "..." }   # may contain simple HTML such as <br> or <a>
show_from: 2026-12-01               # optional, first day it shows
hide_after: 2026-12-25              # optional, last day it shows
```
